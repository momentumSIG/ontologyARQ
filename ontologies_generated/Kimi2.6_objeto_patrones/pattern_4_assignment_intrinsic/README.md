## Overview

This ontology module is generated from a **REIFICATION-CENTRIC** perspective. Every classification, measurement, or interpretation is an assignment made by a researcher, not an intrinsic property of the object.

**Key principle:** NEVER use direct data properties for type, material, chronology, or function. ALWAYS reify through `E17_Type_Assignment` subclasses.

## Source Analysis

This pattern is derived from **Pattern 4: Assignment vs intrinsic property** in `docs/objetoArqueologico/analisis_ontologico_deepseek.md`:

> "Many archaeological 'facts' — material composition, typology, chronology, function, provenance, cultural significance — are NOT intrinsic properties of objects. They are assignments made by researchers based on evidence and interpretation. They must be modeled as reified statements (`E17_Type_Assignment`), not direct attributes."

**CRM mapping:** CRM already provides `E17_Type_Assignment` for this pattern. The archaeological extension models specific sub-types of assignment.
