## Overview

This ontology module is generated from an **EVENT-CENTRIC** perspective. The archaeological event is the primary ontological anchor. Objects participate in events; events carry the semantic weight. Object biography is told as an ordered sequence of events.

**Key principle:** Events are primary ontological entities; objects are participants. Every lifecycle phase is an event subclass of `E5_Event` or its CRM subclasses.
