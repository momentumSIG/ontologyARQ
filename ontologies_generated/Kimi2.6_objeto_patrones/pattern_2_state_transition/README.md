## Overview

This ontology module is generated from a **STATE-CENTRIC** perspective. The archaeological object is primarily a physical entity that undergoes state changes over time. Events are transitions between states. State transitions are not always discrete events — some are gradual, continuous processes.

**Key principle:** Objects are physical entities with measurable condition states. `E3_Condition_State` is the primary pattern for object conditions.
